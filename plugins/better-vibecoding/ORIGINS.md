# Origins

WAWA41 maintains Better Vibecoding in this repository. Its first independent release is 0.1.0. The starting point was Michael Denyer's pstack port, version 0.9.121, at [cd67572](https://github.com/h00mankind/pstack/tree/cd675728babc71ecd8dbc969f6722bcb462b3125), based on Lauren Tan's pstack and work from Cursor. This revision records the origin of the code.

The original [notices](NOTICE.md), [skills notice](NOTICE-skills.md), and MIT licenses for [the port](LICENSE), [Cursor Team Kit](LICENSE-cursor-team-kit), and [Thermos](LICENSE-thermos) ship with the plugin.
