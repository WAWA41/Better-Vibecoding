# Verifying a batch

Run one representative item through the full delivery process. Open the result the way its recipient will and check the property that makes this item correct. For a batch of exports, that might be the selected account's data in the downloaded file.

For each remaining item, choose a cheap check that can distinguish it from the template, a stale result, or another item's output. A successful export or a file count alone can miss all three. If the shared process changes, repeat the end-to-end check and recheck affected outputs.
